# Pastelitos

Statische Website mit Tortenkonfigurator. Die vorbereitete modulare 3D-Asset-Architektur ist in [ASSET-PIPELINE.md](ASSET-PIPELINE.md) dokumentiert.

```sh
npm test
npm run build
```

GitHub Actions führt beide Prüfungen bei jedem Push und Pull Request aus und stellt die validierte statische Website als Build-Artefakt `pastelitos-static-site` bereit.
