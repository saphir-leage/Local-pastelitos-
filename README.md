# Pastelitos

Photorealistischer Three.js-Tortenkonfigurator mit modularer Asset-Pipeline. Details zur Erstellung und Registrierung neuer Assets stehen in [ASSET-PIPELINE.md](ASSET-PIPELINE.md).

```sh
npm test
npm run build
```

GitHub Actions führt beide Prüfungen bei jedem Push und Pull Request aus und stellt die validierte statische Website als Build-Artefakt `pastelitos-static-site` bereit.
